
# Retail Store Sales Data Cleaning

## 📌 Overview
This project focuses on cleaning a dirty retail store sales dataset using Python and Pandas. It identifies data quality issues and prepares the dataset for reliable analysis.

## 🎯 Objectives
- Identify missing values.
- Detect and remove duplicate records.
- Standardize column names and text values.
- Correct data types.
- Detect and handle outliers using the IQR method.
- Generate before-and-after data quality reports.
- Export the cleaned dataset to CSV.

## 📂 Dataset
Dataset: [Retail Store Sales - Dirty for Data Cleaning](https://www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning)

The dataset is downloaded directly from Kaggle using KaggleHub.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- KaggleHub

## ⚙️ Workflow
1. Download and load the dataset.
2. Inspect the data and generate a quality report.
3. Standardize column names and text values.
4. Remove duplicate records.
5. Correct data types and handle invalid values.
6. Handle missing values.
7. Detect and treat numerical outliers.
8. Compare data quality before and after cleaning.
9. Export the cleaned dataset and reports.

## 📊 Output Files
- `retail_store_sales_cleaned.csv`
- `quality_report_before.csv`
- `quality_report_after.csv`
- `outlier_report.csv`
- `before_after_summary.csv`
- Missing-value and outlier visualizations

## ▶️ How to Run
1. Open the notebook in [Google Colab](https://colab.research.google.com/) or Jupyter Notebook.
2. Install the required libraries.
3. Run the code cells in order.
4. Review the reports and download the cleaned dataset.
